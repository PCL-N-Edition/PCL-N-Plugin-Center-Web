**更新日期：** 2026 年 7 月 28 日

**个人信息处理者：** MUXUE1230（个人开发者）

**服务入口：** https://pcln.top/

## 一、适用范围

本协议适用于 N Cloud 统一账户、网页登录与认证门户、桌面设备授权、云端偏好与插件数据、插件市场与发布者工作台、审核与分发、购买权益及相关支持服务。

PCL N 客户端本地处理另见《PCL N Edition 隐私保护协议》。

**首次注册/登录 N Cloud 前，你须确认已阅读并同意本协议及《N Cloud 用户服务协议》。**

## 二、处理原则与法律依据

我们依照合法、正当、必要、诚信与最小范围原则处理个人信息。主要依据包括：订立/履行服务合同所必需、取得同意、履行法定义务、紧急情况下保护生命财产安全，以及法律允许的其他情形。

非必要信息可拒绝提供；拒绝后不应影响无关基本功能（如未登录浏览公开市场）。

## 三、我们处理的信息

### 1. 账户与身份

| 信息 | 用途 | 是否必要 |
|---|---|---|
| 用户 UUID、账户状态 | 创建与识别账户 | 必要 |
| GitHub / Microsoft 提供者 ID | 登录、绑定、防重复账户 | 对相应登录方式必要 |
| 邮箱、用户名、头像 | 识别、通知与资料初始化 | 视提供者返回 |
| 已绑定登录方式 | 账户安全 | 必要 |
| 登录时间、会话状态、失败记录 | 认证与安全 | 必要 |

我们不取得你的 GitHub 或 Microsoft 密码。

### 2. 浏览器本地存储

为保持登录与完成 OAuth，网站可能在本地/会话存储中保存：访问令牌与会话状态、PKCE/OAuth 临时状态、登录提供者与跳转目标、语言/主题偏好、协议同意版本、安全与错误状态。

请勿在公共设备保持登录；退出后我们将清除可控会话数据。

### 3. 公开资料

你主动填写的显示名、头像 URL、简介等可能公开展示。请勿填写身份证号、住址、电话、令牌等不适合公开的信息。

### 4. Microsoft / Xbox / Minecraft

当你选择 Microsoft 登录、所有权验证或桌面配对时，可能处理：Microsoft 账户标识与授权范围、OAuth 令牌、Xbox/Minecraft 过程所需临时令牌、角色名称/标识与是否拥有游戏、令牌刷新状态。

身份令牌属于敏感个人信息，仅用于你明确选择的登录、配对与会话，采取严格访问控制，不公开展示，也不作为普通插件权限提供。

### 5. 设备授权

包括：配对码与状态、设备 ID 与设备名称、授权/最近活动/到期/撤销时间、会话与安全记录、完成配对所需的临时授权信息。

### 6. 偏好、插件授权与插件数据

包括：账户偏好、已授权插件与权限范围、插件专属命名空间数据、创建/修改/同步/删除时间、冲突与错误记录。

默认不允许插件读取其他插件专属数据，除非你明确授权且存在合法业务需要。

### 7. 插件市场与购买

包括：浏览与搜索记录相关的插件 ID/版本/权益查询、外部订单号与核销状态、价格与金额、支持对象选择（如有）、退款/争议与客服记录。

卡号、银行密码等通常由支付服务商直接处理。

### 8. 发布者与组织

包括：组织与成员角色、命名空间与核验材料、插件元数据（多语言名称/摘要/描述/分类/标签）、版本与更新说明、图标与 `.pnp` 包、哈希/签名/撤销状态、扫描与审核记录、上架下架与审计记录。

公开字段将在提交或发布界面标明。

### 9. 财务与提现（功能开放后适用）

可能包括：收款账户标识、收款人名称、销售额/退款/服务费/可提现余额、提现申请状态与理由、依法需要的身份或税务资料。实际收集时将专项提示并依法取得单独同意。

### 10. 网络、安全与诊断

包括：IP、请求时间、路径与状态码、浏览器/OS 等基础设备信息、登录失败与权限拒绝、异常调用与风控结果、服务异常与性能信息、上传/审核/订单/管理操作与安全事件日志。

### 11. 反馈与客服

包括你提交的问题描述、日志、截图、订单凭证、权利证明与沟通记录；桌面端经 N Cloud 提交的 Issue 内容与类型标签亦属此类。

## 四、敏感个人信息

主要包括：OAuth / Microsoft / Xbox / Minecraft 身份令牌；收款与必要金融信息；身份或税务证明；不满十四周岁儿童的个人信息；其他一旦泄露易危害人身财产安全的信息。

仅在具有特定目的与充分必要性时处理，并采取严格保护；法律要求时取得单独同意。

## 五、使用目的

用于：创建与保护账户；连接桌面设备；验证 Minecraft 所有权与建立会话；保存偏好与插件数据；审核、扫描、签名与分发插件；核验订单与管理权益；管理发布者与结算；防欺诈与滥用；处理支持与争议；履行法定义务并改进服务。

## 六、公开展示

1. 公开资料、插件名称/说明/图标、发布者名称、仓库地址、许可证与公开版本信息可能对访客展示。
2. 审核材料、收款信息、访问令牌、设备详情与内部风控记录不公开。
3. 可依法发布安全公告与插件撤销状态，并避免不必要的个人信息。

## 七、共享与委托处理

| 类型 | 服务商/渠道 | 目的 | 范围 |
|---|---|---|---|
| 身份认证 | Supabase Auth、GitHub、Microsoft | OAuth 登录与绑定 | 标识、邮箱、头像、授权信息 |
| 数据库与存储 | Supabase | 账户、业务与插件包存储 | 本协议列明的必要数据 |
| API 与函数 | Supabase Edge Functions（插件中心 API） | 业务接口与受保护写入 | 请求相关的业务与身份上下文 |
| 网站托管 | GitHub Pages、域名/CDN | 页面交付与访问 | IP、请求与基础设备信息 |
| 支付与订单 | 购买页公示的支付/订单服务商 | 收款、查询与退款 | 订单、金额、支付状态 |
| 扫描与诊断 | 插件中心扫描与平台诊断 | 安全与故障分析 | 包文件、日志、异常 |
| 支持渠道 | GitHub Issues 等 | 通知与工单 | 你提交的内容与联系方式 |

我们不向第三方出售个人信息。服务商清单随部署变化时，将通过协议更新或页面公示调整。

## 八、第三方插件

1. 插件在你授权后可能访问特定 N Cloud 服务或插件专属数据。
2. 发布者可能成为独立处理者，应提供自身隐私说明。
3. 我们通过权限清单、隔离、审核与用户授权限制访问，但不能代替发布者履行全部义务。
4. 发现违规处理时，你可撤销授权、删除数据并向我们投诉。
5. Microsoft / Xbox / Minecraft 令牌不作为普通插件权限提供。

## 九、跨境提供

Supabase、GitHub、Microsoft、GitHub Pages 等可能在境外运营或处理数据。是否构成出境取决于项目区域、访问路径与备份位置。涉及出境时，我们将依法告知接收方信息、取得所需同意，并采取加密、权限隔离与最小化措施。正式扩大数据流前，应确认项目区域与子处理者情况。

## 十、保存期限

| 信息 | 原则 |
|---|---|
| 账户与公开资料 | 账户存续期间；注销后依法与备份周期处理 |
| OAuth 与桌面会话 | 有效期间；退出/撤销/失效后删除或不可用 |
| 设备记录 | 授权期间及安全审计所需期限 |
| 插件偏好与数据 | 至删除、服务终止或账户注销 |
| 插件包与版本 | 草稿、审核、发布与必要安全追溯期间 |
| 订单与权益 | 交易、售后、税务与争议所需期间 |
| 财务与提现 | 会计、税务与监管要求期间 |
| 网络与安全日志 | 通常不少于六个月 |
| 客服与投诉 | 处理完成及争议所需期限 |
| 删除后的备份 | 通常在 **30 日** 内覆盖清除 |

届满后删除或匿名化，法律另有规定或未决争议除外。

## 十一、安全保护

包括但不限于：HTTPS；OAuth PKCE 与短期会话；数据库行级安全（RLS）与角色权限；受保护写入 API 与最小权限；对象存储范围限制；插件哈希、开发者签名与市场签名及撤销校验；扫描、人工审核与审计日志；管理员按不可变用户标识授权；备份、监控与事件响应。

你也应使用可信设备、及时退出公共设备，并仔细核对桌面配对码。

## 十二、自动化处理与人工复核

1. 可能使用规则或自动工具识别恶意插件、异常登录、欺诈、上传风险与接口滥用。
2. 对权益有重大影响的决定，应提供说明与人工申诉渠道（GitHub Issues），不以不透明自动化结果为唯一依据。

## 十三、你的权利

你可依法：查阅与复制；更正资料；撤销设备与插件授权；删除插件专属数据；解绑登录方式（至少保留一种可用方式）；撤回同意；请求删除；申请注销；获得处理规则解释；对处理决定申诉。为防冒用，可能验证账户控制权。

## 十四、账户注销

1. 入口以产品内实际路径为准；也可通过 GitHub Issues 申请。
2. 注销前应处理未完成购买、退款、审核、提现与组织权限，并撤销设备、导出必要数据。
3. 注销后删除或匿名化普通账户数据；依法保留的交易、财务、安全、投诉与审计记录除外，且仅用于法定义务与争议处理。
4. 注销可能导致设备会话、云数据与购买权益无法直接访问。

## 十五、未成年人

1. 未成年人应在监护人指导下使用。
2. 不满十四周岁的儿童使用服务前，应取得监护人同意。
3. 对儿童信息采取更严格保护；监护人可通过 GitHub Issues 行使相关权利。

## 十六、安全事件

发生或可能发生泄露、篡改或丢失时，我们将尽快隔离与修复，依法向主管部门报告，并在可能造成危害时通知受影响个人，说明影响、措施与联系方式。

## 十七、协议更新

服务功能、第三方服务商、数据种类或法律要求变化时，我们会更新本协议并调整版本号。重大变化以显著方式告知；依法须重新同意的，将再次征得同意。浏览器与客户端将记录你确认的协议版本。
