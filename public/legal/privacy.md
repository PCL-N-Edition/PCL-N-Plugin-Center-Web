## 一、适用范围

本协议适用于 N Cloud 统一账户、认证门户、桌面设备授权、云端偏好、插件授权和数据、插件市场、发布者工作台、审核、购买权益、财务结算及相关支持服务。

PCL N 客户端本地处理的信息另见《PCL N Edition 隐私保护协议》。

## 二、处理原则和法律依据

我们依照合法、正当、必要、诚信和最小范围原则处理个人信息。主要处理依据包括：

1. 为订立、履行你作为一方当事人的服务合同所必需；
2. 取得你的同意或单独同意；
3. 履行网络安全、消费者保护、税务、争议处理等法定义务；
4. 在紧急情况下保护自然人的生命健康和财产安全；
5. 法律允许的其他处理依据。

非必要信息应允许你拒绝提供，拒绝后不应影响与该信息无关的基本功能。

## 三、我们处理的信息

### 1. 账户和身份信息

| 信息 | 用途 | 是否必要 |
|---|---|---|
| N Cloud 用户 UUID、账户状态 | 创建和识别账户 | 必要 |
| GitHub/Microsoft 提供者 ID | 登录、绑定和防止重复账户 | 对相应登录方式必要 |
| 邮箱、用户名、头像 | 身份识别、通知和初始化资料 | 视提供者返回内容 |
| 已绑定登录方式 | 账户安全和身份管理 | 必要 |
| 登录时间、会话状态、失败记录 | 认证、安全和故障排查 | 必要 |

我们不会取得你的 GitHub 或 Microsoft 密码。

### 2. 浏览器会话和本地存储

为保持登录和完成 OAuth 流程，网站可能在浏览器本地存储或会话存储中保存：

1. 登录访问令牌、会话状态和登录名；
2. PKCE/OAuth 临时状态、登录提供者和跳转目标；
3. 语言、主题及界面偏好；
4. 必要的安全和错误状态。

请勿在公共设备上保持登录。退出账户后，我们会清除可控制的会话数据；浏览器缓存或你手动复制的内容可能需要自行清理。

### 3. 公开资料

你主动填写的显示名、头像 URL 和个人简介可能公开展示。请勿填写身份证号、住址、电话号码、账户令牌或其他不适合公开的信息。

### 4. Microsoft、Xbox 和 Minecraft 信息

当你选择 Microsoft 登录、所有权验证或桌面配对时，可能处理：

1. Microsoft 账户标识及授权范围；
2. OAuth 提供者访问令牌；
3. Xbox/Minecraft 登录过程中所需的临时令牌；
4. Minecraft 角色名称、角色标识和是否拥有 Minecraft；
5. 授权和令牌刷新状态。

身份鉴别令牌属于敏感个人信息。我们仅为你明确选择的登录、配对、所有权验证和桌面会话处理，并采取严格访问控制。令牌不会公开展示或直接提供给第三方插件。

### 5. 设备授权信息

包括：

1. 配对码及配对状态；
2. 设备 ID 和你或客户端提供的设备名称；
3. 授权时间、最近活动时间、到期时间；
4. 撤销时间、会话状态和安全记录；
5. 完成配对所需的提供者类型及临时授权信息。

### 6. 偏好、插件授权和插件数据

包括：

1. N Cloud 账户偏好和同步设置；
2. 已授权插件、权限范围和授权状态；
3. 插件按其专属命名空间保存的数据；
4. 数据创建、修改、同步和删除时间；
5. 处理错误和冲突记录。

我们不应允许插件读取其他插件的专属数据，除非你明确授权且存在合法业务需要。

### 7. 插件市场和购买信息

包括：

1. 浏览、搜索、插件 ID、版本及权益查询；
2. 外部订单号、插件标识、核销状态；
3. 价格、币种、订单金额及权益来源；
4. 超出标价部分的支持对象选择；
5. 退款、撤销、争议和客服记录。

支付卡号、银行密码等通常由支付服务商直接处理。若我们未来直接处理支付信息，将另行告知并采取更严格保护措施。

### 8. 发布者和组织信息

包括：

1. 组织名称、组织标识、slug、成员及角色；
2. 命名空间、核验状态和证明材料；
3. 插件 ID、仓库地址、中英文名称、摘要、描述、分类和标签；
4. 插件版本、渠道、更新日志、最低启动器版本；
5. 图标和 `.pnp` 包文件；
6. 包大小、SHA-256、签名指纹、公钥和撤销状态；
7. 自动扫描结果、人工审核记录、发布者说明和管理员决定；
8. 上架、下架、封禁、申诉及审计记录。

相关资料可能包含发布者公开身份和作品信息。公开字段会在提交前或发布界面中明确标注。

### 9. 财务和提现信息

发布者使用收费功能时，可能处理：

1. 收款账户标识；
2. 收款人姓名或名称；
3. 销售额、退款、服务费和可提现余额；
4. 提现金额、时间、状态、决定和理由；
5. 依法需要的身份、税务或发票资料。

收款账户和身份资料可能属于敏感个人信息，我们会在实际收集时提供专门提示并依法取得单独同意。

### 10. 网络、安全和诊断信息

包括：

1. IP 地址、请求时间、接口路径、响应状态；
2. 浏览器类型、操作系统和必要设备信息；
3. 登录失败、权限拒绝、异常调用和风控结果；
4. 服务异常、堆栈、性能和资源使用信息；
5. 上传、审核、订单、管理员操作和安全事件日志。

### 11. 客服和投诉信息

包括你提交的邮箱、账户标识、问题描述、日志、截图、订单凭证、权利证明和沟通记录。

## 四、敏感个人信息

可能涉及的敏感个人信息主要包括：

1. OAuth、Microsoft、Xbox、Minecraft 身份鉴别令牌；
2. 收款账户、提现和必要的金融信息；
3. 身份或税务证明；
4. 不满十四周岁儿童的个人信息；
5. 其他一旦泄露或者非法使用容易危害人身或财产安全的信息。

我们仅在具有特定目的和充分必要性的情况下处理，并采取严格保护措施。法律要求时，将取得你的单独同意并说明必要性及对权益的影响。

## 五、信息使用目的

我们将信息用于：

1. 创建、登录、绑定和保护账户；
2. 连接和管理 PCL N 桌面设备；
3. 验证 Minecraft 所有权和建立经授权的桌面会话；
4. 保存偏好、插件授权和插件数据；
5. 展示、审核、扫描、签名和分发插件；
6. 核验购买订单和管理插件权益；
7. 管理发布者组织、财务和提现；
8. 防止欺诈、攻击、恶意插件和账户滥用；
9. 处理支持、投诉、退款和争议；
10. 履行法律义务并改进服务。

未经新的合法依据，我们不会将信息用于与上述目的无关的用途。

## 六、公开展示

1. 公开资料、插件名称、说明、图标、发布者名称、仓库地址、许可证及公开版本信息可能向所有访问者展示。
2. 审核材料、收款信息、访问令牌、设备信息和内部风控记录不属于公开内容。
3. 你将个人信息主动写入插件说明、公开仓库或公开资料时，应自行评估公开风险。
4. 我们可以依法公开安全公告、插件撤销状态和必要的风险提示，但应避免公开不必要的个人信息。

## 七、信息共享和委托处理

根据实际部署，可能涉及以下接收方或受托方：

| 类型 | 可能的服务商 | 处理目的 | 信息范围 |
|---|---|---|---|
| 身份认证 | Supabase Auth、GitHub、Microsoft | OAuth 登录和身份绑定 | 账户标识、邮箱、头像、授权信息 |
| 数据库和存储 | Supabase 或Supabase | 账户、业务数据和插件包存储 | 本协议列明的必要数据 |
| 网站托管和网络 | GitHub Pages、域名/CDN 服务商 | 页面交付、安全和网络访问 | IP、请求和基础设备信息 |
| 支付与订单 | 以购买页面公示的支付服务商为准 | 收款、订单查询和退款 | 订单、金额、支付状态 |
| 安全和诊断 | 插件中心自建扫描服务及必要的平台诊断工具 | 漏洞扫描、故障和攻击分析 | 包文件、日志、异常信息 |
| 客服和通知 | GitHub Issues 及必要的系统通知渠道 | 发送通知和处理请求 | 邮箱、消息和工单 |

正式上线前，我们将以《第三方信息共享清单》公布服务商名称、联系方式、处理目的、信息类型和隐私政策入口。

我们不会向第三方出售个人信息。

## 八、第三方插件

1. 插件可能在你授权后访问特定 N Cloud 服务或插件专属数据。
2. 插件发布者可能成为独立的个人信息处理者，应提供自己的隐私政策和联系方式。
3. 我们通过权限清单、隔离、审核和用户授权限制插件访问，但无法代替发布者履行全部法定义务。
4. 发现插件违规处理个人信息时，你可以撤销授权、删除插件数据并向我们投诉。
5. 我们不会将 Microsoft、Xbox 或 Minecraft 令牌作为普通插件权限提供。

## 九、跨境提供

Supabase、GitHub、Microsoft、GitHub Pages 及其他服务商可能在中华人民共和国境外运营或处理数据。是否构成个人信息出境，取决于实际部署区域、访问权限和数据流。

涉及个人信息出境时，我们将：

1. 公布境外接收方名称或类型、联系方式、处理目的、处理方式、信息种类和权利行使方式；
2. 取得法律要求的单独同意；
3. 开展个人信息保护影响评估；
4. 根据适用门槛完成标准合同备案、认证、安全评估或其他程序；
5. 采取加密、密钥管理、权限隔离和最小化措施；
6. 监督境外接收方按照约定处理信息。

在正式启用相关数据流前，应确认 Supabase 项目区域、运维访问区域、备份位置和各服务商的子处理者。

## 十、保存期限

| 信息 | 保存原则 |
|---|---|
| 账户和公开资料 | 账户存续期间；注销后按法律和备份周期处理 |
| OAuth 和桌面会话 | 会话有效期间，退出、撤销或失效后删除或使其不可用 |
| 设备记录 | 授权期间及安全审计所需期限 |
| 插件偏好和数据 | 至你删除、插件终止服务或账户注销 |
| 插件包和版本 | 草稿、审核、发布和必要安全追溯期间 |
| 订单和权益 | 履行交易、售后、税务和争议处理所需期间 |
| 财务和提现记录 | 按会计、税务和监管要求保存 |
| 网络和安全日志 | 按法律要求保存，通常不少于六个月 |
| 客服和投诉记录 | 处理完成及必要争议期限 |
| 删除后的备份 | 在至多 30 日内逐步清除 |

达到保存期限后，我们将删除或匿名化，法律另有规定或存在未决争议的除外。

## 十一、安全保护

我们根据风险采用：

1. HTTPS 等传输加密；
2. OAuth PKCE、短期会话和令牌刷新控制；
3. 数据库行级安全策略和角色权限；
4. Bearer Token、受保护写入 API 和最小权限；
5. 对象存储签名 URL 和上传范围限制；
6. 插件 SHA-256、开发者签名、市场签名和撤销校验；
7. 插件自动扫描、人工审核和审计日志；
8. 管理员权限按不可变用户标识授予；
9. 备份、监控、漏洞修复和事件响应；
10. 对敏感数据实行更严格的访问审批和日志记录。

你也应使用可信设备、及时退出公共设备、保护第三方账户并核对桌面配对码。

## 十二、自动化处理和人工复核

1. 我们可能通过规则或自动工具识别恶意插件、异常登录、重复订单、欺诈、上传风险和接口滥用。
2. 自动扫描结果可能影响插件审核、账户访问或交易处理。
3. 对你的权益产生重大影响的决定，应提供说明和人工申诉渠道，不以不透明的自动化结果作为唯一依据。
4. 你可以通过GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）申请人工复核。

## 十三、你的权利

你可以依法：

1. 查阅和复制账户、公开资料、设备、插件授权和其他个人信息；
2. 更正显示名、头像、简介和不准确资料；
3. 撤销设备和插件授权；
4. 删除插件专属数据；
5. 解绑登录方式，但至少应保留一种可用登录方式；
6. 撤回基于同意开展的处理；
7. 请求删除不再必要或违法处理的信息；
8. 申请注销账户；
9. 获取个人信息处理规则的解释；
10. 对处理决定或权利请求答复提出申诉。

为防止冒用，我们可能验证账户控制权。法律规定可以拒绝或限制请求时，我们会说明理由。

## 十四、账户注销

1. 注销入口为：账户设置 → 注销账户（上线后以产品内实际路径为准）；也可以发送邮件至GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）。
2. 注销前应处理未完成的购买、退款、审核、提现和组织权限。
3. 注销后，我们会删除或匿名化普通账户数据；依法必须保存的交易、财务、安全、投诉和审计记录除外。
4. 注销可能导致设备会话、插件授权、云数据和购买权益无法直接访问。你应在注销前导出必要数据。
5. 对依法保留的数据，我们将限制其仅用于法定义务、安全和争议处理。

## 十五、未成年人信息

1. 未成年人应在监护人指导下使用 N Cloud。
2. 不满十四周岁的儿童使用服务前，应取得监护人同意。
3. 对儿童个人信息，我们会制定专门处理规则、限制访问并采取严格保护措施。
4. 未成年人个人信息处理情况将按适用规定进行合规审查。
5. 监护人可以通过GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）行使查阅、更正、删除和撤回同意等权利。

## 十六、安全事件

发生或可能发生个人信息泄露、篡改或丢失时，我们将：

1. 立即采取隔离、撤销令牌、修复和风险控制措施；
2. 按法律要求向主管部门报告；
3. 在可能造成危害时，以邮件、站内通知、公告或其他有效方式通知受影响个人；
4. 说明事件类型、可能影响、已采取措施、个人可采取的措施和联系方式。

## 十七、协议更新

1. 服务功能、第三方服务商、数据种类、处理目的或法律要求变化时，我们会更新本协议。
2. 对敏感个人信息、跨境提供、公开披露或其他重大变化，将以显著方式告知。
3. 依法需要重新取得同意的，不以继续使用或单纯公告代替明确同意。
