# N Cloud 用户服务协议

**版本号：** v0.2  
**更新日期：** 2026 年 7 月 28 日  
**生效日期：** 2026 年 7 月 28 日  
**运营者：** MUXUE1230（个人开发者）  
**联系方式：** GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）  
**服务入口：** https://pcln.top/ （认证辅助域名可能包括 auth.pcln.top）

## 一、协议范围与接受

1. **N Cloud** 是 PCL N 的在线服务体系，包括：统一账户与 OAuth 登录、网页工作台与插件市场、桌面设备授权、云端偏好与插件数据、插件上传/审核/分发、购买权益，以及后续明确上线的服务。
2. **首次注册或登录 N Cloud（含通过 GitHub / Microsoft OAuth 创建账户）前，你须阅读并勾选同意本协议及《N Cloud 隐私保护协议》。** 不同意的，请勿登录或使用需账户的功能；公开市场浏览可不登录。
3. 本协议与商品页、收费规则、发布者规则、活动规则共同构成约定；专项规则优先，但不得减损消费者法定权利。
4. PCL N 客户端本地使用另受《PCL N Edition 用户服务协议》约束。

## 二、账户注册与身份绑定

1. 当前支持通过 **GitHub**、**Microsoft** 等身份提供者完成登录；我们不取得你的第三方账户密码，仅接收提供者返回的标识、邮箱、头像等授权信息。
2. 同一邮箱原则上对应一个 N Cloud 账户。新增登录方式须在已登录账户中主动绑定，不会仅凭邮箱自动合并两个账户。
3. 你应保证资料真实、有权使用，不得冒用他人身份、组织或商标。
4. 不得出售、出租、共享账户或批量注册。
5. 发现未授权登录或设备连接时，应立即撤销设备并联系支持。

## 三、公开资料

1. 显示名、头像、简介等标记为公开的资料可能展示在市场、发布者页等位置。
2. 不得发布违法内容、他人个人信息、误导性官方标识或侵权内容。
3. 公开后第三方缓存可能保留副本；我们在可控范围内处理删除请求，但不保证第三方同步消失。

## 四、Microsoft / Xbox / Minecraft 与桌面会话

1. 使用 Microsoft 登录或连接桌面端时，可能验证 Minecraft 所有权与档案信息。
2. 相关令牌仅用于你授权的账户与设备服务，不写入公开资料，也不直接提供给第三方插件。
3. 你可以撤销设备授权；撤销后该设备需重新配对登录。
4. 因 Microsoft 等第三方规则或接口变化导致的功能变化，由相关责任方依法承担责任。

## 五、桌面设备授权

1. 连接 PCL N 桌面端时，应核对网页与客户端显示的配对码，仅批准你实际控制的设备。
2. 每台设备可建立独立会话，记录设备名称、授权时间、最近活动、到期与撤销状态。
3. 配对码具有临时授权性质，不得公开或输入来源不明的页面。
4. 对异常配对、批量设备、令牌重放等风险，我们可拒绝授权或撤销会话。

## 六、云端偏好、插件授权与插件数据

1. N Cloud 可保存账户偏好、插件权限范围及插件专属命名空间下的数据。
2. 插件仅应获得你明确授权的范围；你可以调整授权或申请删除对应数据。
3. 卸载本地插件不等于自动删除云端数据；删除入口以产品实际提供的功能或支持渠道为准。
4. 插件不得获得 Microsoft / Xbox / Minecraft 令牌。
5. 重要存档与唯一副本请勿仅依赖云端；请自行备份。

## 七、插件市场

1. 市场提供插件展示、搜索、审核相关状态、签名信息、下载与更新等服务。
2. 插件页应展示发布者、版本、价格（如有）、权限、许可证与兼容性等重要信息。
3. 除标明由我们直接提供外，第三方插件由发布者提供；我们提供平台技术、审核辅助与分发服务，并依法履行平台义务。
4. 审核、扫描与签名核验用于降低风险，不构成对插件无缺陷或永久兼容的保证。
5. 对恶意、侵权、签名异常或重大漏洞插件，我们可暂停分发、撤销版本或提示卸载。

## 八、免费与付费插件

1. 免费插件可在符合页面条件后取得使用权益。
2. 付费插件以页面展示的模式为准（例如一次性购买）；**未明确提供自动续费时，不会自动续费。**
3. 价格、税费、权益范围、支持期限与退款规则以购买页面为准。
4. 支付由购买页公示的支付/订单服务商处理；你须遵守其规则。
5. 平台可通过订单号核验已完成的外部订单并授予权益。不得提交伪造、已退款、属于他人或已使用的订单。
6. 权益通常绑定购买账户；除法律另有规定或页面明确允许外，不得转售、出租或共享。
7. 若付费能力尚未对你所在环境开放，相关条款在功能实际上线后适用。

## 九、退款与售后

1. 在线交付的数字化商品，在依法显著告知并经你确认后，可能不适用七日无理由退货；但不影响法定质量问题救济。
2. 未交付、重复扣款、核验失败或法律要求退款的，可通过购买页说明或 GitHub Issues 申请处理。
3. 第三方插件功能与售后由发布者负责；我们提供投诉转送、权益冻结与争议协助。
4. 退款后对应权益可被撤销。

## 十、发布者、命名空间与上传

1. 发布前应创建/加入发布者组织并申请命名空间；不得冒用他人名称、商标或项目。
2. 上传的代码、资源与说明须具有合法权利，如实填写元数据与权限理由，不得含恶意程序、后门、隐蔽挖矿或规避安全措施的代码。
3. 需要处理个人信息时，发布者应提供独立隐私说明并遵循最小必要原则。
4. 发布者应妥善保管签名私钥；泄露时应立即申请撤销与轮换。
5. 平台可计算哈希、核验签名、自动/人工审核，并保存审计记录。
6. 不得通过覆盖相同版本号、替换已审包等方式破坏可验证性。

## 十一、签名与在线验证

1. 正式分发包须符合平台签名规则；平台可为通过审核的包添加市场签名。
2. PCL N 安装市场插件时，可联网核对 SHA-256、发布者、命名空间、签名指纹与撤销状态。
3. 验证失败、包被篡改或验证服务不可用时，首次安装可能被拒绝。
4. 签名表示来源与完整性经过相应核验，不等于对功能与商业价值的担保。

## 十二、结算与提现

1. 发布者可在平台允许范围内设置免费或一次性收费。
2. 服务费、渠道费、最低提现额、结算周期等以发布者结算页公示为准。
3. 发布者应提供准确收款信息并自行承担依法税费；我们可依法要求提供必要证明或代扣代缴。
4. 对欺诈、侵权、退款争议或异常订单，可依法暂缓结算并通知发布者。
5. 拒绝提现应说明合理原因，并允许通过 GitHub Issues 申诉。
6. 未成年人不得独立发布收费插件或提现，除非由监护人或适格主体依法办理。
7. 若结算功能未开放，相关条款在功能上线后适用。

## 十三、用户内容与知识产权

1. 发布者保留对插件与资料依法享有的权利。
2. 为审核、存储、扫描、展示、分发与更新，发布者授予我们实现上述目的所必需的非独占许可。
3. 开源插件应遵守所声明许可证，不得故意删除第三方版权声明。
4. 侵权投诉可通过 GitHub Issues 提交；我们可依法通知、移除或恢复。

## 十四、禁止行为

不得：伪造身份/订单/签名/审核结果；上传恶意或侵权内容；绕过购买权益、RLS、API 权限或安全扫描；攻击或滥用接口；出售账户或会话；诱导用户提交密码与令牌；违法处理未成年人信息；其他严重损害平台或用户权益的行为。

## 十五、审核、风控与申诉

1. 我们可结合自动扫描与人工审核处理插件、账户与交易风险。
2. 对权益有重大影响的决定，不以不透明自动化结果为唯一依据，可申请人工复核。
3. 下架、封禁、拒绝审核、冻结权益等决定，可通过 GitHub Issues 申诉。
4. 紧急安全事件可先采取临时措施，再在合理期限内补充说明。

## 十六、账户注销与服务终止

1. 你可通过产品入口（上线后以实际路径为准）或 GitHub Issues 申请注销。
2. 注销前应撤销设备、导出必要数据，并处理未完成订单、审核、退款与提现。
3. 注销后普通账户数据按隐私协议删除或匿名化；依法须保留的交易、安全与审计记录除外。
4. 已购数字权益可能因账户标识删除而暂时无法访问；我们应保留合理核验与售后机制。
5. 严重违法、攻击、欺诈或重大安全风险下，可依法终止账户并提供必要通知与申诉渠道。

## 十七、服务变更与可用性

1. N Cloud 持续开发中，功能可能新增、调整或终止。
2. 对付费权益、个人信息处理、结算等重大变化，将提前以显著方式通知。
3. 维护、故障、攻击、云服务中断或不可抗力可能导致暂时不可用；我们尽合理努力恢复。

## 十八、责任承担

1. 各方按过错与法律规定承担责任。
2. 平台审核不免除发布者对插件的责任，也不免除平台依法应尽义务。
3. 不排除故意、重大过失、人身损害、侵犯个人信息权益或法律不得排除的责任。
4. 消费者法定权利不受不当排除。

## 十九、未成年人

1. 未成年人应在监护人指导下使用。
2. 不满十四周岁的儿童创建账户或使用云服务前，应取得监护人同意。
3. 购买、发布收费插件、提现或处理他人信息，应由具备相应行为能力的主体进行。
4. 监护人可通过 GitHub Issues 申请查询、限制或删除相关信息。

## 二十、法律适用与争议解决

1. 适用中华人民共和国大陆地区法律。
2. 争议先协商；协商不成可向有管辖权的人民法院起诉。
3. 可依法向消费者组织或主管部门投诉。
