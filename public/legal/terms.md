# N Cloud 用户服务协议

**客服邮箱：** GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）

> 本文件为依据当前项目功能起草的协议草案。正式发布前，应由实际运营主体结合账户、订单、结算、退款、税务、未成年人和跨境业务情况进行法律复核。

## 一、协议范围

1. N Cloud 是 PCL N 的在线服务体系，包括统一账户、网页登录、桌面设备授权、云端偏好、插件授权和数据、插件中心、购买权益、发布者组织、插件审核、分发、财务结算以及后续明确上线的服务。
2. 你访问 N Cloud 网站、创建账户、连接 PCL N 桌面端、购买插件或使用发布者功能，即表示接受本协议及《N Cloud 隐私保护协议》。
3. 本协议与具体页面上的商品说明、收费规则、发布者规则和活动规则共同构成服务约定。存在冲突时，专项规则优先，但不得减损消费者法定权利。

## 二、账户注册与身份绑定

1. N Cloud 可以通过 GitHub、Microsoft 或我们另行支持的身份提供者完成登录。
2. 我们不会取得你的第三方账户密码，但会接收身份提供者返回的账户标识、授权信息和必要资料。
3. 同一邮箱原则上只对应一个 N Cloud 账户。新增登录方式必须从已登录账户主动绑定，不会仅凭邮箱自动合并两个账户。
4. 你应提供真实、准确且有权使用的资料，不得冒用他人身份、组织、商标或发布者资格。
5. 账户仅限你本人或依法获得授权的组织成员使用。不得出售、出租、共享或批量注册账户。
6. 发现未经授权的登录、身份绑定或设备连接时，应立即撤销设备并联系支持。

## 三、公开资料

1. 你可以设置显示名、头像地址和个人简介。标记为公开的资料可能展示在插件市场、发布者页面或其他公开位置。
2. 不得在公开资料中发布违法内容、他人个人信息、误导性官方标识、恶意链接或侵权内容。
3. 公开后，搜索引擎、浏览器缓存或第三方存档可能保留副本。我们会在可控制范围内处理删除请求，但无法保证第三方副本同步消失。

## 四、Microsoft、Xbox 和 Minecraft 档案

1. 你选择 Microsoft 登录或连接桌面端时，N Cloud 可能验证 Minecraft 所有权和档案名称。
2. Microsoft、Xbox 或 Minecraft 令牌只应用于你授权的账户和设备服务，不会写入公开资料，也不会直接开放给第三方插件。
3. 你可以撤销设备授权。撤销后，该设备需要重新登录。
4. 因 Microsoft、Xbox 或 Minecraft 服务规则、授权状态、地区限制或接口变化造成的功能变化，由相关责任方依法承担责任。

## 五、桌面设备授权

1. 连接桌面端时，你应核对网页和桌面端显示的配对码，仅批准你实际控制的设备。
2. 每台设备可以建立独立会话，并记录设备名称、授权时间、最近活动、到期和撤销状态。
3. 配对码具有临时授权性质，不得公开、转发或输入到来源不明的页面。
4. 我们可以对异常配对、批量设备、令牌重放或其他安全风险拒绝授权或撤销会话。

## 六、云端偏好、插件授权和插件数据

1. N Cloud 可以保存账户偏好、插件权限范围以及插件专属数据。
2. 插件仅应获得你明确授权的范围。你可以调整授权或删除对应插件数据。
3. 删除插件不当然等于删除其云端数据；产品应提供独立删除入口或由客服处理。
4. 插件发布者处理经授权的数据时，应遵守其隐私政策和适用法律。插件不得获得 Microsoft、Xbox 或 Minecraft 令牌。
5. 重要存档和唯一副本不应只保存在测试性质的云服务中。你应保留必要备份。

## 七、插件市场

1. 插件市场提供插件展示、搜索、审核、签名验证、下载、更新、购买权益和发布者服务。
2. 插件页面应展示发布者、版本、价格、权限、许可证、兼容性和其他重要信息。
3. 除页面明确标注由我们直接提供外，第三方插件由对应发布者提供。我们主要提供平台技术、审核、分发和交易辅助服务，并依法履行平台责任。
4. 审核、扫描和签名核验用于降低风险，不构成对插件无缺陷、完全安全、适合特定用途或永久兼容的绝对保证。
5. 插件存在恶意代码、重大漏洞、侵权、虚假描述、签名异常或其他风险时，我们可以暂停分发、撤销版本、阻止安装或通知用户卸载。

## 八、免费插件和付费插件

1. 免费插件可以在符合页面条件后取得使用权益。
2. 付费插件实行一次性购买或页面明确展示的其他模式。当前未明确提供自动续费时，不会自动续费。
3. 价格以人民币显示，具体金额、税费、权益范围、支持期限和退款规则以购买页面为准。
4. 支付可能由以购买页面公示的支付服务商为准完成。你需要遵守该服务商规则，并可能向其提供支付所需信息。
5. N Cloud 可以通过订单号核验已完成的外部订单并授予插件权益。不得提交伪造、已退款、属于他人或已被使用的订单。
6. 当订单付款金额超过插件标价时，页面可以允许你选择将超出部分用于支持发布者或平台。该选择应在核销前明确展示。
7. 权益通常绑定至购买账户。除法律另有规定、页面明确允许或客服核验同意外，不得转售、出租、共享或转移。
8. 插件价格或未来版本收费发生变化，不影响已依法取得的既有权益范围；但新产品、重大独立版本或额外服务可以另行收费并提前说明。

## 九、退款和售后

1. 在线交付并开始下载、激活或取得访问权益的计算机软件等数字化商品，在购买页面依法显著告知并经你确认后，可能不适用七日无理由退货。
2. 不适用无理由退货不影响插件存在无法交付、与描述严重不符、恶意代码、权利瑕疵或其他法定质量问题时，你依法要求修复、更换、退款或赔偿的权利。
3. 尚未交付、重复扣款、订单核验失败或法律规定应退款的，可以通过购买页面说明或 GitHub Issues申请。
4. 第三方发布者负责其插件功能和售后；我们会提供投诉、证据转送、权益冻结和争议协助，并依法履行平台义务。
5. 退款后，对应插件权益可以被撤销。因安全下架导致无法继续提供服务时，按照法律、商品页面及实际使用情况处理。

## 十、发布者组织和命名空间

1. 发布插件前，应加入或创建发布者组织并申请命名空间。
2. 组织管理员应确保成员授权真实有效，并及时移除离职、退出或不再有权限的成员。
3. 命名空间和插件 ID 不得冒用他人名称、商标、组织或开源项目。
4. 我们可以要求提供域名、代码仓库、商标授权、组织关系或其他必要证明。
5. 组织状态、成员角色、命名空间核验和审核记录可以作为平台风控和争议处理依据。

## 十一、插件上传、审核和发布

发布者保证：

1. 对上传的代码、资源、名称、图标、说明和依赖具有合法权利；
2. 如实填写中英文名称、摘要、说明、版本、兼容性、权限理由和更新日志；
3. 不包含恶意程序、后门、凭据窃取、隐蔽挖矿、勒索、未经授权的遥测或规避平台安全措施的代码；
4. 不越权访问文件、账户、网络、剪贴板、输入设备或其他系统资源；
5. 需要处理个人信息时，提供独立隐私政策，遵循最小必要原则并取得所需同意；
6. 妥善保管 OpenPGP 私钥，发生泄露时立即申请撤销和密钥轮换；
7. 配合安全扫描、人工审核、漏洞处置和用户投诉；
8. 不通过覆盖相同版本号、替换已审核包或其他方式破坏可重复验证性。

平台可以计算包哈希、解析清单、核验签名、进行自动和人工安全检查，并保存审核及审计记录。

## 十二、签名和在线验证

1. 正式插件包必须符合平台签名规则。
2. 平台可以保留开发者签名，并为通过审核的分发包添加市场签名。
3. PCL N 安装市场插件时，可以在线核对包 SHA-256、发布者、命名空间、签名指纹和撤销状态。
4. 在线验证失败、签名无效、包被修改或验证服务不可用时，首次安装可能被拒绝。
5. 签名表示包来源和完整性经过相应验证，不等于平台对全部功能、安全性或商业价值作担保。

## 十三、定价、结算和提现

1. 发布者可以在平台允许范围内设置免费或一次性收费模式。
2. 平台服务费、支付渠道费、退款分担、最低提现金额和结算周期为：以发布者结算页面公示规则为准。
3. 发布者应提供准确的收款账户和收款人信息，并自行承担依法应缴纳的税费。
4. 我们可以依法代扣代缴税费，或者要求发布者提供税务、身份和收款证明。
5. 对涉嫌欺诈、侵权、退款争议、安全事件、洗钱风险或异常订单的款项，可以依法暂缓结算并通知发布者。
6. 提现申请和管理员处理应保留审计记录。拒绝提现时，应说明合理原因并提供申诉渠道。
7. 未成年人不得独立申请发布收费插件或提现，除非由其监护人或适格经营主体依法办理。

## 十四、用户内容和知识产权

1. 发布者保留对插件和资料依法享有的权利。
2. 为提供审核、存储、扫描、展示、分发、备份和更新服务，发布者授予我们实现上述目的所必需的非独占许可。
3. 开源插件应遵守所声明的开源许可证；不得故意删除第三方版权、NOTICE 或许可证文件。
4. 权利人可以通过GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）提出投诉。我们可以依法采取通知、移除、断开链接或恢复措施。
5. 发布者与用户之间的开源许可、商业许可或售后承诺应在插件页面清晰说明。

## 十五、禁止行为

不得：

1. 伪造身份、订单、签名、审核结果、销量、评价或提现资料；
2. 上传恶意软件、侵权内容或违法信息；
3. 绕过购买权益、访问控制、RLS、API 权限、上传限制或安全扫描；
4. 攻击、爬取、压测或干扰服务；
5. 出售或共享账户、设备会话、插件权益或发布者权限；
6. 诱导用户提交密码、令牌、恢复密钥或不必要的个人信息；
7. 利用插件处理未成年人信息而不履行特别保护义务；
8. 从事其他违法或严重损害平台、用户、发布者权益的行为。

## 十六、审核、风控和申诉

1. 我们可以结合自动扫描和人工审核判断插件、账户、订单和提现风险。
2. 自动结果原则上不应作为对用户权益产生重大影响的唯一依据；你可以申请人工复核。
3. 对下架、封禁、拒绝审核、冻结权益或拒绝提现等决定，我们应提供GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）。
4. 紧急安全事件可以先采取临时措施，再在合理期限内补充说明。

## 十七、账户注销和服务终止

1. 你可以通过产品入口或GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）申请注销账户。
2. 注销前应撤销设备、导出必要数据并处理未完成的订单、审核、退款、提现和争议。
3. 注销后，公开资料和普通云端数据将按隐私协议删除或匿名化；依法必须保存的交易、安全和审计记录除外。
4. 已购数字权益可能因账户标识删除而暂时无法访问。我们应保留合理的订单核验和售后机制，不得以注销账户免除法定义务。
5. 发布者账户注销前应完成组织权限移交、用户支持和财务结算。
6. 严重违法、恶意攻击、欺诈或重大安全风险下，我们可以依法终止账户，并提供必要通知和申诉渠道。

## 十八、服务变更和可用性

1. N Cloud 仍可能处于持续开发阶段。我们可以新增、调整或终止功能。
2. 对付费权益、个人信息处理、开发者结算或其他重大事项的变化，将提前以显著方式通知。
3. 维护、故障、攻击、第三方云服务中断或不可抗力可能造成暂时不可用。我们会尽合理努力恢复和保护数据。
4. 终止付费服务时，我们会依照法律、已购权益和服务实际履行情况提供迁移、继续使用、退款或其他合理方案。

## 十九、责任承担

1. 各方按照过错和法律规定承担责任。
2. 平台安全审核不免除发布者对插件承担的责任，也不免除平台依法应承担的审核、处置和消费者保护责任。
3. 任何条款均不排除故意、重大过失、人身损害、侵犯个人信息权益、欺诈或法律不得排除的责任。
4. 用户依法享有的消费者权利不因格式条款而被排除。

## 二十、未成年人

1. 未成年人应在监护人指导下使用 N Cloud。
2. 不满十四周岁的儿童创建账户或使用云服务前，应取得监护人同意。
3. 购买、发布收费插件、提交提现或处理他人个人信息，应由具备相应民事行为能力的主体进行。
4. 监护人可通过GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）申请查询、限制或删除相关账户信息。

## 二十一、法律适用和争议解决

1. 本协议适用中华人民共和国大陆地区法律。
2. 争议应先通过客服协商；协商不成的，可向依法有管辖权的人民法院起诉。
3. 消费者可以依法向消费者协会、市场监督管理部门、网信部门或其他主管机关投诉。
